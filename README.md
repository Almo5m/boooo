# 🎓 بوت إدارة جروب الصف الثالث الثانوي

بوت تليجرام إداري + تعليمي كامل، بأوامر عربي طبيعية، وشخصية ذكاء اصطناعي بتتفاعل مع الطلاب، مع لوحة تحكم ويب مودرن.

## المميزات

**كل الأوامر بالعربي** — تتكلم مع البوت بكلامك العادي، من غير `/` ومن غير إنجليزي. مثال: رد على رسالة حد واكتب "احظر" أو "اكتم 10" أو "حذر مخالف للقوانين". شوف اللستة الكاملة بكتابة `/help`.

**شخصية "بو" الذكية داخل الجروب:**
- البوت اسمه "بو" (قابل للتغيير)، وبيرد كإنه عضو حقيقي في الجروب، مش رسمي ومش جامد.
- بيتفاعل تلقائي على: السلام والتحية، سؤال مباشر بينتهي بـ"؟"، رد على رسالته، أو مناداته بالاسم.
- في الخاص بيرد على أي رسالة عادية (مش بس لما تناديه).
- شغال بـ Groq / OpenRouter / Gemini (اختار مزوّد مجاني واحد). لو مفعلتش أي مفتاح، البوت هيقولك كده بأدب بدل ما يتجاهلك.

**🎛 لوحة تحكم كاملة من الخاص على تليجرام:**
- ابعت `/start` أو "لوحة" للبوت في الخاص (لو انت المالك أو مشرف مضاف) وهتلاقي قائمة أزرار: المواد، الأسئلة، الاختبارات، الجدولة، المشرفين، الإعدادات، الإحصائيات.
- بدء اختبار في أي جروب بضغطة زرار (من غير ما تكتب حاجة في الجروب نفسه).
- جدولة رسالة بخطوات بسيطة (اكتب المحتوى → اختار الجروب → اختار التوقيت).
- إضافة/حذف مشرف بفوروارد رسالة منه أو بآيديه.

**📎 رفع الأسئلة من ملف إكسيل:**
- من لوحة الخاص: المواد → الأسئلة → اختار المادة → ابعت ملف `.xlsx`.
- ترتيب الأعمدة: السؤال | اختيار١ | اختيار٢ | اختيار٣ (اختياري) | اختيار٤ (اختياري) | رقم الإجابة الصحيحة (0=الأول) | شرح (اختياري) | الصعوبة (اختياري).
- البوت بيتجاهل أي صف فيه مشكلة ويقولك سبب التجاهل بالظبط.

**👥 نظام مشرفين — تحكم مقصور عليك وعلى اللي تضيفه بس:**
- كل أوامر التحكم (حظر، كتم، إعدادات، اختبارات...) شغالة بس مع المالك (`OWNER_IDS`) والمشرفين المضافين من الخاص أو من لوحة الويب — مش أي أدمن تليجرام عادي في الجروب.
- ضيف مشرف تاني من لوحة الخاص (👥 المشرفين) أو من صفحة `/admins` على الويب.

**الإدارة (زي Rose / Group Butler):**
- حظر / كتم / طرد / رفع حظر / فك كتم (رد على رسالة العضو)
- نظام تحذيرات تلقائي (٣ تحذيرات = حظر، قابل للتعديل من اللوحة)
- تثبيت / إلغاء تثبيت رسائل
- قفل الروابط / التوجيه (forward) / الاستيكرات
- فلاتر كلمات (حذف تلقائي + رد اختياري)
- ملاحظات محفوظة بكلمة مفتاحية (`#note`)
- رسالة ترحيب مخصصة للأعضاء الجدد + قوانين الجروب

**التعليمي (بنك أسئلة + اختبارات):**
- بنك أسئلة لكل مادة، تضاف يدوي من اللوحة أو دفعة واحدة من إكسيل
- بناء اختبار من مجموعة أسئلة، مع وقت محدد لكل سؤال
- تشغيل الاختبار داخل الجروب كـ Telegram Quiz Poll حقيقي (من الجروب بكتابة "ابدأ اختبار [رقم]" أو من لوحة الخاص بضغطة زرار)
- تصحيح تلقائي + لوحة نتائج (Leaderboard) في آخر الاختبار
- كل طالب يقدر يشوف نتائجه بكتابة "نتايجي"

**جدولة الرسائل:**
- رسالة لمرة واحدة في وقت محدد، أو متكررة (Cron) زي كل يوم الساعة ٦ مساءً
- خيار تثبيت الرسالة تلقائي بعد إرسالها
- إدارة كاملة من لوحة الخاص، أو الويب، أو من داخل الجروب ("الرسايل المجدولة"، "الغاء الجدولة [رقم]")

**لوحة التحكم (ويب) — تصميم فاتح مع رسوم بيانية وانتقالات:**
- تسجيل دخول بيوزر وباسورد
- إدارة المواد / الأسئلة / الاختبارات / الجدولة / المشرفين / إعدادات كل جروب
- رسمين بيانيين تفاعليين (عدد الأسئلة لكل مادة، واتجاه آخر النتائج) + إحصائيات سريعة

## تفعيل الدردشة الذكية (مجاني)

عندك ٣ اختيارات، اختار واحد بس وحط مفتاحه في Variables على Railway:

| المزوّد | مميزاته | رابط التسجيل |
|---|---|---|
| **Groq** (الافتراضي) | سريع جدًا، مجاني تمامًا | [console.groq.com](https://console.groq.com) |
| **OpenRouter** | فيه موديلات مجانية متنوعة | [openrouter.ai](https://openrouter.ai) |
| **Gemini** | من جوجل، حدود يومية مجانية | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

الخطوات:
1. سجّل حساب مجاني عند المزوّد اللي هتختاره واعمل API Key.
2. في Variables على Railway ضيف:
   ```
   AI_PROVIDER=groq
   GROQ_API_KEY=gsk_xxxxxxxxxxxx
   BOT_PERSONA_NAME=مستر روبوت
   ```
   (لو هتستخدم OpenRouter أو Gemini، غيّر `AI_PROVIDER` وحط `OPENROUTER_API_KEY` أو `GEMINI_API_KEY` بدل GROQ_API_KEY)
3. البوت هيرد تلقائي لو حد رد على رسالته أو كتب اسمه أو "يا بوت"/"يا مساعد".

> ملحوظة: ذاكرة المحادثة بسيطة (آخر ٦ رسائل لكل جروب) وبتتصفر لما البوت يعيد التشغيل — كفاية للتفاعل الطبيعي بدون تعقيد إضافي.

## التشغيل محلياً (اختباري)

```bash
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# افتح .env واملأ BOT_TOKEN و OWNER_IDS على الأقل
python main.py
```
هيشتغل البوت + لوحة التحكم مع بعض على `http://localhost:8000`.

## خطوات الرفع على Railway

1. اعمل بوت جديد من **@BotFather** على تليجرام وخد الـ Token.
2. اعرف الآيدي بتاعك من **@userinfobot**.
3. ادفع الكود ده على مستودع GitHub خاص بيك.
4. من [railway.app](https://railway.app) اعمل **New Project → Deploy from GitHub repo**.
5. من تبويب **Variables** ضيف:
   - `BOT_TOKEN`
   - `OWNER_IDS`
   - `DASHBOARD_USERNAME`
   - `DASHBOARD_PASSWORD`
   - `SECRET_KEY` (أي نص عشوائي طويل)
   - `DATABASE_URL` (سيب `sqlite:///./edubot.db` أو وصّل Postgres من Railway لو عايز بيانات أضمن مع كل ديبلوي)
6. Railway هيحط `PORT` تلقائي، متلمسهاش.
7. بعد الديبلوي، Railway هيديك رابط عام (Public Domain) — فعّله من Settings → Networking، وده رابط لوحة التحكم.
8. ضيف البوت لجروب الصف الثالث الثانوي، وخليه أدمن (عشان يقدر يحظر/يكتم/يثبت).
9. ابعت أي أمر زي `/rules` جوه الجروب عشان يتسجل في قاعدة البيانات، وبعدين هتلاقيه في صفحة **الإعدادات** باللوحة.

## ملاحظة عن SQLite على Railway
SQLite بيتمسح لو الديبلوي اتعمل من غير Volume. لو عايز البيانات تفضل محفوظة بين كل ديبلوي:
- اعمل **Volume** من Railway وحط `DATABASE_URL=sqlite:////data/edubot.db` مع تركيب الفولوم على `/data`، أو
- استخدم **Railway Postgres Plugin** وحط رابطه في `DATABASE_URL` (الكود شغال مباشرة مع Postgres من غير أي تعديل).

## الأوامر داخل الجروب
شوف الأوامر كاملة بكتابة `/help` جوه الجروب بعد تشغيل البوت. الأوامر كلها عربي وبتتكتب عادي في الشات، غير `/start` و`/help` بس اللي فضلوا بصيغة تليجرام القياسية.
